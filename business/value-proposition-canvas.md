## Shared Value Map Summary

Our offer has three layers that are relevant across all segments:

**1. Local AI with fine-tuned model**
Deployed on the client's own infrastructure. Trained on their procurement history. No data sent to external APIs. Gets more accurate over time.

**2. Specification-to-supplier matching + comparison report**
Takes a material specification and returns a ranked, multi-criteria comparison of matching suppliers — price, delivery, quality, certifications, reliability, sustainability. Output is audit-ready.

**3. Explainability**
Every recommendation includes a reasoning trail: which criteria drove the result, which data was used, where it came from. Designed for human review, management approval, and audit.

## Strategic Observations

**Segments A and B are the right dual focus at launch.**
Both have severe pain, strong offer fit, and a credible path to revenue. The construction company is faster to close; the municipality opens a replicable market (one reference unlocks many). Run them in parallel.

**Segment E (suppliers) is a data strategy, not a revenue strategy yet.**
Onboarding suppliers as data partners early — before a paid tier exists — builds the matching engine asset that makes segments A, B, and C more valuable. Start this now, unpaid, with suppliers relevant to first buyer clients.

**Segment C is the prize, but not the starting point.**
Sovereign IT fit is perfect. But the 12–24 month sales cycle and missing supply-chain-risk features make it a V2 target. Use a research partnership (Windesheim + infrastructure org) to build the reference and gather requirements.

**The minimum training data threshold is a cross-segment qualification tool.**
Once established, it tells you which prospects qualify for fine-tuning and which need a base model or lighter product tier. This threshold is different per segment — enterprise orgs have more data than project developers.
